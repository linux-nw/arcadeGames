# ARcade

**Status:** 🟢 Active

Collection of classic browser games (HTML, CSS, JavaScript): 2048, Minesweeper, PacMan, Pong, Snake and Tetris, all reachable from one shared start page.

**Name:** An arcade is the amusement hall where these classics used to stand.

---

## Usage

1. Clone or download the repo.
2. Open `Startside/index.html` in a current desktop browser.
3. Pick a game and play.

No installation and no dependencies needed.

---

## Repo structure

```
Startside/   start page with the game selection
2048/  Minesweeper/  PacMan/  Pong/  Snake/  Tetris/   one game each (HTML, CSS, JS)
fonts/       local font
```

---

## Privacy

Runs offline as static files, nothing is transmitted.
